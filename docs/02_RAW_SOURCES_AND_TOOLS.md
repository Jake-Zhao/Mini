# 02 · 原始素材、分类与具体方法

## 素材不是都叫“图片”
| 类别 | 理想的最原始输入 | 本包真实状态 | 应当产生什么 |
|---|---|---|---|
| 审美参考 | 用户最后确认的原图，不反复压缩截图 | `Reference/APPROVED.png` | 构图/轮廓/亮度主次约束，不能直接当材质 |
| 车辆外观 | 无损原片/RAW、固定机位、车体完整；需要几何时有多视角与尺度 | 用户后侧照片676×451已收录；不是RAW或扫描 | 轮廓、涂装、灯罩、车牌、接地点 |
| 透明覆盖 | 原图上人工轮廓、轮胎/镜子/尾翼孔隙 | `registration.json`与三个PNG遮罩 | coverage alpha，而不是“暗部=透明” |
| 表面材料 | 同一表面、相同尺度的漫反射/法线/高度/粗糙度；含采集光照说明 | 已提供确定性程序化生成配方；没有实测扫描 | 分角色贴图，不把高光同时烘焙进基础色与反射 |
| 光照参考 | HDR曝光包围组、灰/色卡、灯具位置/尺寸、相机曝光记录 | 未采集；本版使用明确的艺术灯光常数 | 曝光、灯色与亮度关系，不能从8bit效果图恢复HDR |
| 运动参考 | 已知快门和帧率的原始运动片段、镜头参数、时间同步车速 | 未采集；使用米/秒与透视投影的明确模型 | 近远光流、快门长度、雾流速度 |
| 字形 | 0–9全套可编辑轮廓、笔锋纹理、可见边界与字距 | 15个SVG母版＋固定图集度量已收录 | 同一数字着色器，不拼72截图；不是命名字体 |
| 车辆数据 | GATT服务/属性、原始通知字节、单调时间、命令和ECU来源 | 未采集；只有明确DEMO夹具与接口 | 有来源/时效/会话的数据，不编造刹车/挡位 |
| 权利信息 | 资产授权文本与来源 | 用户源照片权利未独立确认；自制处理步骤有记录 | 不把“网上能看到”当成可无条件商用 |

`Config/asset_provenance.json` 是机器可读登记。所有运行依赖都在包内，采集层面的空缺没有伪造填补。

## 分类后的目录
`Source/` 是可编辑母版；`Resources/` 是确定性编译出的运行数据；`Reference/` 只供审美比对；`Config/` 定义单位、图层和来源；`Evidence/` 只放实际执行的离线检查与诊断。没有历史设计或SHA清单。

## 方法与工具：区分本次使用和可选生产工具
| 工作 | 本次实际使用 | 可选人工精修工具；本次未运行 |
|---|---|---|
| 全车轮廓与材质区域 | 手工注册点、Pillow/OpenCV、线性RGB重着色 | Krita路径/透明遮罩或Photoshop钢笔工具；使用非破坏遮罩 |
| 材质构建 | NumPy/SciPy周期场、物理尺度梯度、固定seed | Substance Designer或Blender节点；或授权扫描PBR |
| 字形 | 15个固定SVG、CairoSVG、可见alpha边界测量 | Inkscape逐字轮廓/负空间检查，不寻找“近似字体” |
| 相机与代理 | Swift解析投影、Metal共享相机公式 | Blender相机匹配、几何灰模、接地位置比对 |
| 颜色合成 | 线性sRGB、float16预乘、明确mipmap与采样规则 | OCIO管理的合成环境；选用时记录配置，不混用不明view transform |
| 运动与后期 | MSL场景曝光积分、GPU水雾、独立HUD合成 | Blender/Cycles离线对照、RenderDoc离线GL探针调试；非本轮必需 |
| 确定性检查 | Python断言、Swift XCTest、Linux Swift语法解析、Mesa/EGL片元探针 | 后续Apple工具检查；本轮不运行 |

这些工具不是“装上就会高级”。每个工具对应一个明确问题。当前包不依赖Krita/Blender/Nuke/Substance才能重新生成运行资产。

## 可公开获取的原始材质候选
官方发布页已经核对：Poly Haven `asphalt_02`标示3米尺度，`concrete_wall_001`标示1.5米尺度；其实际资产采用CC0，但网站展示渲染等不等同于CC0资产。

**本环境没有成功下载这些贴图，包中没有冒称使用它们。** 当前道路/墙面是自制程序化数据；其存在让代码方案自包含，但不等于达到了摄影扫描材质的观感。不得用这些候选的名字给现有纹理背书。

## 实拍任务单（非本轮前置条件）
固定后侧机位拍摄车体完整原片，保留元数据和原文件；车灯关闭/制动发光分别拍摄，避免曝光不同引起误比较；灰卡/尺度参考独立一帧；材质记录视场实际宽度；运动片段同时记录快门、帧率、相机位置与同步车速。不得以驾驶者手持操作完成采集。没有这些数据时继续使用已声明的固定视角近似，不伪造“实拍已验证”。
