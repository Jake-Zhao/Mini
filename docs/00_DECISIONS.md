# 00 · 决策与范围

## 深入的定义
本轮不是增加页面、特效名词或素材数量，而是建立一个可追溯的闭环：**输入源 → 图像/时间/空间约定 → 实际代码 → 可证伪的检查 → 仍然存在的视觉差距**。没有原始数据的地方写明假设，不把概念图当物理测量，也不把通过测试当达到审美目标。

唯一视觉目标为 `Reference/APPROVED.png`。它负责视觉主次、形状语言、综合色彩和动势；不能从它唯一恢复真实相机、法线、深度、基础色或动态曝光。

## 已定内容
JAKE DRIVE；iPhone-only；横屏两个方向；iPhone 15 Pro；Vgate iCar Pro 2S BLE；绿色 MINI F56 60周年；当前实现范围是 PURE 原生渲染实验工程。后续 OBD 和完整产品不在本轮冒充已完成。

PURE：可见车速轮廓位于全屏水平/垂直中心；挡位小而清晰，位于数字右下；小车在右下道路，保留绿车身、红尾翼和拉花、苏U·K27D5蓝牌；上半部暗二进制雨向道路渐隐。没有米字旗、km/h、RPM、大标题或常驻产品导航。实验控制台不属于产品UI。

所有数字共用同一字形图集和着色器。背景模糊不可污染数字、挡位。零速装饰停止；模拟、回放、真实来源严格区分。真实挡位和刹车默认未知，不用车速或减速度猜。

## 本轮交付边界
包含全部**当前代码运行需要**的材质、字形、车辆、遮罩、配置、源素材、源处理脚本、Swift/Metal源码、项目描述和离线检查。无需任何旧包，也无需联网下载纹理才可开始。

不包含尚未采集的真实RAW、多视角扫描、实车GATT转储、真实油车制动/挡位解码器。不把小尺寸照片放大称为“原生4K”。不把程序化纹理写成扫描PBR。原车图片来源权利未独立验证。

按本次要求，不执行 Xcode、Apple Metal 编译器或 iPhone 检查。离线检查是本轮的完成证据，画质达标仍单独保留待验收，不能因为“不要求真机”而宣布已经还原。

## 不采用的捷径
不整屏播放确认图/视频；不写死72；不对所有背景统一放大；不按图像亮度删除车身；不把2D车贴图当可任意转向/真实重打光模型；不增加未经原生输出证明的“光线追踪、MetalFX、全物理PBR”标签。
